# الجداول والكود
حافظ على الاقتران بين headers وقيم rows، وعلى ترتيب الأعمدة المعتمد في المصدر. عند طلب عكس عرض الأعمدة انقل العناوين والقيم معًا وتحقق من خلية معروفة بعد التصدير. أبقِ الجدول قابلًا للتحرير والمعادلة في خليتها.
انقل VHDL كاملًا ضمن حقل نص مسموح، مع الأسطر والمسافات واتجاه LTR عند العرض. تحقق من entity وarchitecture والإشارات وقائمة الحساسية والتعريفات التي يعتمد عليها التوصيل. في مثال جامع هرمي يتطلب 1-bit و4-bit معًا، احفظ التعريفين والربط بينهما. تحقق بالمحاكي عند توافره وميّز فحص النص من اختبار التنفيذ. لا تنشئ نوع code غير معرّف في Schema.
