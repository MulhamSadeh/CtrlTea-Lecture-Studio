# من التفريغ إلى ملزمة
احتفظ بتعريف الفكرة وشروطها وتفسير الرموز، ثم صِلها بالمثال الذي يبيّن استعمالها. اختر ترتيبًا يخدم الموضوع ولا تفرض مقدمة أو خاتمة ثابتتين. ادمج الجمل التي تكرر الادعاء نفسه، واحتفظ بتنبيه يغير فهم الحل حتى لو استعمل عبارة شائعة. مثل «في هذا التفريغ» غالبًا زائد، لكن الحكم يتبع وظيفة العبارة.
استعمل definition وrule وexplanation وفق وظيفة النص. example للمثال الوصفي، وexercise حين يلزم problem وsteps وresult. استعمل list لعناصر حقيقية وordered حين يؤثر الترتيب. ضع عنوان الفكرة مرة واحدة؛ القالب يضيف تسميات الأنواع. اجعل الفهرس قابلًا للدراسة وحافظ على العناوين اليدوية خارج نطاق الطلب.
