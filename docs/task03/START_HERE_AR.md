# Ctrl+Tea Lecture Studio — Task03

المشروع يدعم SQLite المحلية وPostgreSQL مع ملكية خاصة لكل مستخدم مستقبلًا. لا توجد مصادقة أو مشاركة بين الحسابات بعد؛ هذه نسخة تطوير محلية.

ابدأ بـ[دليل الإعداد](DATABASE_SETUP.md)، ثم [نتائج الاختبارات](TEST_RESULTS.md) و[تقرير التنفيذ](DATABASE_IMPLEMENTATION_REPORT.md).

حزمة المشاركة لا تحتوي بيانات التشغيل أو المصادر والـfixtures الخاصة؛ احتُفظ بها في النسخة الخاصة الأصلية. تحتاج استعادة examples من تلك النسخة لتشغيل الاختبارات التاريخية الكاملة. اختبارات قاعدة البيانات الجديدة تُنشئ أمثلتها المؤقتة.
