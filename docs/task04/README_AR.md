# تسليم Task04 — Ctrl+Tea Lecture Studio V2

24 تشرين الأول2026. تنفيذ فعلي انطلاقًا من UPDATED_PROJECT.zip للمهمة03، مع الحفاظ على النسخ السابقة. لم تُنفّذ المهمة05 ولم يحدث نشر عام.

## النتيجة

التسجيل بالبريد وتفعيله، الدخول والخروج واسترداد كلمة المرور والجلسات الآمنة، تهيئة SuperAdmin بدعوة مؤقتة، وصوله الإداري الشامل إلى بيانات جميع الأعضاء، وإدارة الصلاحيات والتعليق وإعادة التنشيط. لكل عضو مساحة خاصة وبروفايل بوصف عمل يكتبه بنفسه، مع دليل أعضاء ولوحة إدارة وسجل عمليات. وصف العمل لا يمنح صلاحيات. الخادم يفرض التفويض على المحتوى والملفات والسجل والمهام؛ المدير يعمل بهويته دون كلمة مرور العضو.

المصادقة مطلوبة افتراضيًا؛ الإعداد الناقص يتوقف بدل فتح المحرر دون حماية. الوضع المحلي القديم لا يعمل إلا بطلب AUTH_MODE=local الصريح، وهو للاستخدام المحلي المعزول فقط. تبقى واجهة تحرير المحاضرة ومكوّن المعادلات كما هما، مع طبقة الحسابات الجديدة.

## البداية

ابدأ بـSUPER_ADMIN_SETUP.md. بعد إعداد PostgreSQL وخدماته المقيدة، شغّل الترقية0002، سجّل حساب المالك وفعّل بريده، ثم استخدم الأمر المحلي المحمي:

```bash
python -m ctrltea.bootstrap invite --email "$CTRLTEA_OWNER_EMAIL"
```

البريد متغير يحدده المالك بعد التحقق منه، وليس حسابًا جاهزًا. الدعوة30دقيقة ولمرة واحدة، مرتبطة بالحساب المتحقق؛ يلزم الدخول وتأكيد التفعيل ثم الدخول مجددًا. لا توجد كلمة مرور مسؤول أو أسرار داخل الحزمة.

## الملفات والحدود

UPDATED_PROJECT_TASK04.zip يحتوي المصدر والواجهة المبنية وتعليمات04. CtrlTea_Task04_Reports.zip يحتوي التقارير والأدلة المقبولة. MODIFIED_FILES.md يسرد كل تغيير مقارنة بمصدر03. ملفات الأمثلة العلمية التاريخية الخاصة غير مضمنة في الأرشيف القابل للمشاركة، كما في03؛ تبقى في النسخة الاحتياطية الخاصة لتشغيل الاختبارات التاريخية كاملة.

البريد اختُبر عبر صندوق محلي آمن؛ لم يُختبر التسليم الخارجي أوDNS. يوجد مزودSMTP قابل للإعداد، وفشله يسجّل ويحتاج إعادة إرسال؛ لا يوجد outbox دائم. العمليات الإدارية الحساسة تستخدم إعادة تأكيد كلمة المرور، ولا يُدّعى تنفيذMFA. يلزم قبلstaging بيئةPostgreSQL/عرض مدعومة ومحدّثة، وعزل أدوات التحويل، وتخزين خاص مستمر ونسخ احتياطي/استعادة، وتسليم بريد حقيقي وضبطHTTPS. هذه متطلباتTask05 الموثقة وليست تنفيذًا لها.

البيانات التشغيلية الأصلية للمستخدم لم تُرفق، لذلك لا توجد هجرة فعلية مزعومة. السجل والملفات وأدلة الاختبارات موثقة بحدودها. الخطأ في الرد السابق كان اعتماد مهمة02 من السياق دون مطابقة مواصفة04؛ هذا التسليم يخص04 فقط.
