# ضبط أدلة المصدر
اربط كل تعريف وشرط وخطوة مطلوبة بصفحتها، وسجّل موضعها في القسم الناتج. افحص طرفي المثال إذا امتد بين صفحتين. ارجع إلى صورة الأصل لحسم التباس OCR، مع بقاء الصفحات المستبعدة خارج النطاق حتى إن ظهرت في الملف الأصلي الكامل.
عند اختلاف المصدر الأساسي مع كتاب داعم اذكر موضع الخلاف وتفسيره في issue واقترح clarification أو correction ضمن العقد. إذا تعذر التحقق احتفظ بالجزء الموثوق وأبق المهمة غير مكتملة عند غياب جزء لازم. لا تنشئ وصلة أو معطى أو وحدة لإغلاق المسألة. ميّز السؤال المنقول حرفيًا من الشرح المؤلف.
